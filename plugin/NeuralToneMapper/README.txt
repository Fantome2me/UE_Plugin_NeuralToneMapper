确认的故障是 SDR 合成策略：1.1.5 默认让照片网络的 RGB 完全取代了经调色、曲线和显示限制处理后的 RGB。同机位与原生 UE 对照，可复现暗部整体抬高。这不是证明所有绿斑或单个边缘都来自该模型。160x96 照片训练与 UE 场景和分辨率有差异；训练直接接收归一化 PNG，UE 则先压缩曝光后的场景 RGB，两者未做实景标定。独立测试数据上的相对 MAE 降幅是约 32.4%，不是 24%，也不是画质提升百分比。160x96 经两级降采样是 40x24；保留并重建频带的金字塔并不等于把模糊缩略图直接放大。

修正范围：保留旧显示曲线及调色的全分辨率输出。AI 仍运行注意力、三张 LUT 和完整的学习式多尺度重建；其 RGB 只给后续滤波层提供条件，不再直接显示。重建纹理的 alpha 单独累计学习式频带相对恒等重建的亮度修正。零频带不贡献修正；大反差边缘衰减。最终只乘统一 RGB 增益，限制在 +/-0.18 档以内，并在近黑和近峰值逐渐退回基准输出。此限制针对新增 AI 修正，不是对基础曲线的保证。此次未重训，未修改旧输入权重，未将照片输出当成 UE 或 HDR 真值。二进制接口未变，沿用已构建模块；其历史 LLF 启动日志仍写 1.1.5，插件描述符为 1.1.6 / 117。

两个实际工程：独立游戏进程、默认地图、800x450、固定时间步、第 76 帧。对照顺序为原生 UE、1.1.5、新版。以 8 位 RGB 通道的平均绝对像素差衡量与原生的距离，不是感知评分，也不是物理亮度。
StarSky：原生/旧/新通道均值 52.16 / 92.89 / 45.15；旧/新对原生 MAE 41.37 / 8.78。新版暗部略低于原生。
