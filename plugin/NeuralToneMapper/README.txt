NTM 1.1.7 | UE 5.8 Win64 | 默认 Neural、LLF 开启、Intensity=1 的 SDR 通路

目标：由图像网络的全局 LUT、空间注意力和局部重建参与生成最终 LDR RGB，而非像 1.1.6 那样只取 alpha。新 RGB 解码器把有界场景输入 sqrt(x/(1+x)) 和预训练 LLF 的重建 RGB 合并，输出目标 sRGB 码值。转回线性后按目标 SDR 设备编码。黑输入在解码器输出端固定为零，SDR 编码后仍有原有量化抖动。旧曲线在默认满强度 SDR 下不决定最终 RGB；非满强度混合及 LLF 关闭仍可用。HDR 走 1.1.6 有界校正，不拿 JPEG 或 SDR 截图作为绝对亮度目标。仍是参考文章思想的实现，不是作者架构或权重的逐层复刻。

训练：本机 RTX 5060 Ti。保留已有注意力、三张 17^3 LUT 和局部滤波器，训练 6 输入/24 隐单元/3 输出解码器。输入是同机位采样的场景与 LLF 特征（8 位诊断截图，推理使用 GPU 浮点特征），标签是 UE 原生实际截图。损失包含暗部加权的像素误差、相对通道色差、水平/垂直邻域梯度差及平均色偏。采用附件的高低频分工与结构/颜色约束；未采用扩散、256-bin 直方图预测或 Canny。未宣称全网联合重训。

验收资产 SM_Item_TuDiMiao_02，Lvl_ThirdPerson，世界包围盒中心 (1192.70,-1191.47,89.02)。六机位 800x450 固定时间步，0..3 训练，4 选权重，5 独立验收（同一物体，不是跨场景测试）。验收位置 (1040,-1350,115)，Pitch -7、Yaw 46。中心裁切 x=[285,515), y=[150,300)，不是精确材质遮罩。以原生图的加权码值亮度 5..40 选出 7074 个像素。训练输入、原生、旧版、新版为独立游戏进程，不排除小的时间/抗锯齿差异。
原生 / 1.1.6 / 1.1.7：暗部中位数 16.99 / 12.76 / 19.00；暗部亮度 MAE 0 / 4.31 / 2.05。四暗阶原生中位数 8.5、16.8、24.3、32.8；1.1.6 为 5.1、12.6、19.6、27.0；1.1.7 为 9.8、18.8、26.0、32.8。
整个裁切区：去每像素通道均值后的颜色分量 MAE 5.28 -> 1.98（非 CIE Delta E）；原始 RGB MAE 9.98 -> 10.11，没有全面超过旧版。StarSky 另做启动渲染检查；未验收长期时序、4K 帧耗、物理 HDR 或所有材质。旧曲线特征和手动 scRGB 枚举的历史问题未在此次 SDR 功能更新中修复。
两个项目已安装；不上传 GitHub。黑位与颜色的人工验收请查看土地庙对照图，左原生、中 1.1.6、右 1.1.7。Shader-only 更新沿用已编译 DLL，历史模块启动日志中的 1.1.5 指早期 LLF 内核，不是描述符版本。
