# NTM 1.0.3 — 修正「效果反了」

> **发布于 2026-11-15**
> 下载：`NTM1.0.3.zip`（1.39 MB）· UE 5.8 Win64

## 一句话

1.0.2 的问题：**暗部细节没变化，亮部更明显**，和 1.0.1 刚好相反。查下来这是架构缺陷，不是参数没调好。这一版修正它。

---

## 根因（两层，都有数据）

### 第一层：Durand 细节恢复天生是「高光操作」

1.0.2 的校正幅度 ∝ `|detail| × (1 − 曲线斜率)`。

SDR 曲线在**暗部斜率接近 1**、**高光斜率很小** —— 所以这个算子的能量天然集中在高光。

更要命的是：`(G1-G3)`、`(G0-G1)`、`(curve(G3)−curve(G0))` **全是频带差，局部零均值**。任何组合都无法把一片均匀的暗区整体提亮。

1.0.1 之所以能让暗部动，是因为它的增益乘在**曲线之前**，曲线陡峭的趾部把暗部变化放大了。

### 第二层：显示域有上限，对称对比度增强会净提亮

实测：任何强度下校正都让整帧变亮。

原因：显示码值钳制在 1.0 —— 高光被削、阴影不被削，于是对称的 ± 增强在统计上产生**正的均值偏移**。

这就是"发灰"的机制。

---

## 改了什么

### 1. 混合域校正（关键改动）

校正纹理改成 `RG16F`，两个通道作用在**不同域**：

```
R = 场景参考增益（stops）  →  乘在曲线【之前】
G = 显示参考偏移（stops）  →  乘在 LUT 【之后】
```

理由：局部曝光物理上就是场景亮度操作，放在曲线前才能被陡峭的趾部放大 —— 这正是 1.0.1 让暗部动起来的原因。而细节补偿必须放在曲线后，否则会被曲线重新压回去。

### 2. 曝光参考从 G3（1/16）换成 G1（1/4）

在 1/16 分辨率上，明亮表面旁的狭窄阴影早被平均掉了，曝光项"看不见"那里是暗的。

实测：用 G3 时 0.05–0.15 输出带只动 **+0.004 档**；换 G1 后提升到 **+0.024 档**。

### 3. 第 4 个局部通道：局部曝光（DC 项）

3 个频带差无法表达"整片提亮"，所以增加第 4 个通道：

```
s_low × clamp(局部亮度 − 帧均值, −3, +3)
```

输出契约 **56 → 72 维**（8 曲线 + 64 局部）。

### 4. 冻结主干训练（新增 `--freeze-backbone`）

加了 64 维局部头之后，如果全网络一起训，局部损失（72 个输出里占 64）会把主干拖离曲线最优位置。

实测：一起训时 knot val 从 **0.32 恶化到 0.54**。

改成只训局部头（主干冻结）：

| | 一起训 | **冻结主干** |
|---|---|---|
| 曲线 L1 | 0.54 | **0.321** |
| 局部参数 corr | — | **0.76** |

### 5. 测试中否掉的两个错误做法（都写进代码注释了）

- 直接用 `s_low × Exposure` 双向作用 → 整帧 +0.11 显示亮度，画面发灰
- 只把系数符号钳负 → 没用，因为系数本来就是负的，**偏置来自项而不是权重**

|---|---|---|---|


## 仍然存在的限制（不掩饰）

1. **最深的阴影（输出 <0.15）变化仍小**（+0.024 档）。1/4 分辨率参考对成片暗区有效，对亮表面旁的**细窄阴影**检测不到 —— 那需要全分辨率局部参考。
2. **整体比 UE 原生亮约 +0.31 档**。+0.19 来自曲线（v8 在 100 nit 面板预测峰值 +0.21 档，被物理钳制后顶部压平、中调抬高），+0.12 来自局部算子。
3. **强度不能再往上推**。曝光 1.0 时整帧 +0.42 档，画面明显发灰。

## 下一步的正确做法（建议）

要让暗部真正像 1.0.1 那样打开、同时不发灰，需要在**标签生成阶段**解决，而不是在着色器里：

1. 教师参考里显式模拟显示钳制，求解「净亮度漂移为零」的局部参数
2. 用**全分辨率**局部参考判定「这里是不是暗区」
3. 或改用任务型局部教师：噪声感知 + 高光细节滚降

接缝都已留好：4 通道参数、边缘条件、混合域链路、`LocalExposureScale` / `LocalDetailMix` 两个强度旋钮。

---

## 新增设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| `Local Exposure Scale` | 0.5 | 局部曝光强度（0 = 只用细节带） |
| `Local Detail Mix` | 0.25 | 局部细节强度（1 = Durand 全强度） |

## 升级注意

- 输出契约 56 → 72，**旧模型不兼容**（自动退回解析曲线，不崩溃）
- 校正纹理格式 `R16F → RG16F`
