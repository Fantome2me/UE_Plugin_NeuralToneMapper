# 检查点

三个已训练好的权重，对应三个发布版本。都是 `torch.save` 的 dict：

```python
{"model": state_dict, "epoch": int, "val": float, ...}
```

直接用 `export_onnx.py --ckpt <文件>` 就能导出 ONNX，不需要原数据集。

| 文件 | 大小 | 产物 | 说明 |
|---|---|---|---|
| `best_v6b.pt` | 3.65 MB | `NTMO_M_v6.onnx` → **NTM 1.0.1** | 48 通道输入 / 8 输出（只有全局曲线），局部算子用三个手调常数 |
| `best_v7b.pt` | 3.76 MB | `NTMO_M_v7.onnx` → **NTM 1.0.2** | 49 通道（加了边缘）/ 56 输出（8 曲线 + 48 局部） |
| `best_v8b.pt` | 1.37 MB | `NTMO_M_v8.onnx` → **NTM 1.0.3 / 1.0.4** | 49 通道 / 72 输出（8 曲线 + 64 局部），冻结主干训出来的 |

## 为什么 v8b 只有 1.37 MB

另外两个包含**优化器状态**（Adam 的 `exp_avg` / `exp_avg_sq`，各一份浮点参数），
所以约为纯权重的 2.7 倍。v8b 是在冻结主干的模式下训的，保存时没有带优化器状态。

这不影响使用：`train.py --init-from` 和 `export_onnx.py --ckpt` 都只读 `["model"]` 里的权重，
有优化器状态会顺带恢复，没有就从零开始。
